> **DnnManager.NET** — one app to rule your local DNN environments.

| Feature | What it does |
|---|---|
| 📁 **Project management** | All your local DNN sites in one place |
| 🖥️ **IIS control** | Create, start, stop and configure sites & app pools |
| 🗄️ **Databases** | SQL Server attach, backup, restore, clone |
| 📜 **Logs** | Tail DNN & IIS logs without digging through folders |
| ♨️ **Keep-warm** | No more cold-start waits on dev sites |
| 🧬 **Clone** | Spin up a copy of a site in seconds |
